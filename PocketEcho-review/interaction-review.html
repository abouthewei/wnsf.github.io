实体按键
与操作逻辑评审

PocketEcho 是一款强调实体交互、离线使用、弱屏幕甚至无屏幕体验的便携音乐播放器。评审重点不是“按钮有多少”，而是用户拿起设备后，能否自然地完成播放。

本次评审目标：识别语义映射、学习成本、认知冲突与反馈风险，并用现有硬件收敛出一套统一的操作语言。

用户不需要阅读说明书，不依赖屏幕菜单，就可以完成绝大多数播放操作。

02 / Overall Evaluation

方向正确，
但语义还没有完全统一

当前方案整体合理，实体交互也形成了产品辨识度。风险集中在长按过多、隐藏功能不易发现，以及无屏状态下的反馈不完整。

合理之处

  • 01高频操作都有独立实体入口
  • 02音量使用旋钮自然；按压播放 / 暂停符合成熟播放器认知
  • 03拨杆带来机械感和产品辨识度
  • 04滑动开关可以形成“位置即状态”
  • 05Tag 取出键、电量 LED 都具备清晰的实体语义
当前方案综合评价7 / 10

需要继续优化

  • 01控件与功能之间的语义映射还没有完全统一
  • 02长按操作偏多，低频功能容易被隐藏
  • 03蓝牙状态机需要覆盖“已连接”后的关闭与换机路径
  • 04快进 / 快退尚未很好地融入现有硬件
  • 05Reset 是 PocketEcho 的特殊逻辑，需要额外反馈与文案
优先级最高Reset / 蓝牙

04 / Issue 01

最大的认知问题：
Reset 的功能语义

旋转和短按都属于当前播放控制；长按 Reset 却切换到了播放状态管理。它不是常见的“重新播放当前歌曲”，而是恢复到歌曲初始 / 未播放状态。

同一个旋钮，跨越了两种心理模型

用户可以自然推断“旋转调音量”“按压播放 / 暂停”，但很难仅靠传统播放器经验猜到“长按音量旋钮 = Reset 当前歌曲状态”。

旋转当前播放控制
短按当前播放控制
长按播放状态管理

保留候选方案，但把反馈做完整

长按约 2 秒缩短等待，降低误判
LED 跑马 / 闪烁明确告诉用户动作已被识别
重置播放完成恢复歌曲初始状态
建议文案：“重置播放” / “重新开始”
05 / Issue 02

让曲目拨杆
成为导航核心

不增加额外按钮，通过“短拨”和“保持”把歌曲导航与时间轴导航分开。这样既保留机械感，也让硬件承担更多连续操作。

拨杆操作示意

↑ Hold快退
中心自动回弹
↓ Hold快进

短拨 = Track Navigation
保持 = Timeline Navigation

短操作控制“歌曲”；持续操作控制“歌曲时间轴”。这是 PocketEcho 最具有产品辨识度的实体操作之一。

向上短拨上一曲
向下短拨下一曲
向上保持快退，松手停止
向下保持快进，松手停止

07 / Principles

PocketEcho
Interaction Principles

这套原则不是为了让用户记住更多操作，而是让每一种操作维度都拥有稳定、一致的心理模型。

让用户根本不需要学习操作

90% 的日常播放场景，应该只需要两个核心控件：播放旋钮 + 曲目拨杆。

01 / 一个控件，一个核心认知One Control, One Mental Model
02 / 短操作高频，长操作低频短操作执行高频动作；长操作执行低频动作。
03 / 物理位置表达持久状态位置不是触发器，而是可被持续读取的系统状态。Physical Position = System State
04 / 持续动作控制连续参数旋转 → Volume；保持拨杆 → Seek。
05 / 无屏设备必须强化反馈LED 动效、机械回弹与声音反馈要形成固定语义。
06 / 90% 高频只依赖两个控件Playback Control + Track Navigation。

理想用户路径

04旋钮调音量Rotate / Volume

PocketEcho 不应该追求
“用户记住所有操作”，而应该追求
“用户根本不需要学习操作”。

08 / Control Strategy Comparison

把风险留在
最容易理解的控件上

旋钮沿用 TimeEcho 的播放控制心智模型；上一曲 / 下一曲改成独立按钮，避免“旋转到底是切歌还是快进”的歧义。音量再由独立拨杆承接，三类动作彼此分开。

A / 当前方案

EXISTING LOGIC
播放旋钮旋转音量；短按播放 / 暂停；长按 Reset
曲目拨杆短拨上一曲 / 下一曲；保持快退 / 快进
认知结构两个控件分别承担播放控制与曲目 / 时间轴导航

优点：控件数量少，方向语义基本成立。
风险：音量旋钮和播放控制共用一个输入；拨杆的短拨与保持需要学习。

B / 独立按键版

RECOMMENDED TO TEST
播放旋钮旋转快退 / 快进；短按播放 / 暂停；长按 Reset
曲目控制上一曲 / 下一曲使用独立按钮，点击即执行
音量拨杆上 / 下调整音量；保持时连续变化，松手回中

优点：播放、曲目、音量三个意图拆开；更接近 TimeEcho 的旋钮习惯。
代价：需要确认机身空间，并增加独立音量与曲目输入的结构成本。

建议：先把 B 作为独立分支进入模拟和盲操作测试；如果音量拨杆的操作精度不够，再回退为“旋钮音量 + 独立上一曲 / 下一曲按钮”的保守版本。
09 / Conclusion
7
当前方案综合评价 / 10

不建议在未验证前继续增加新的实体按键

  • 优先解决 Reset 的语义与反馈
  • 按连接意图组织蓝牙状态，补齐已连接态操作
  • 将上一曲 / 下一曲作为独立按钮分支验证
  • 建立一致的 LED 状态语言
  • 旋钮沿用 TimeEcho 的播放控制逻辑
  • 确认音量拨杆的阻尼与反馈

最终目标：减少按钮数量，减少隐藏逻辑，减少用户记忆，强化实体反馈，建立 PocketEcho 自己的操作语言。
