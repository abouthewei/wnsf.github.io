01 / 推荐架构

推荐结论：POLPO 是主品牌；PocketEcho 是产品名称；WowNow 是外部生态；Works with WowNow 是兼容认证标识。

02 / Badge 与产品呈现

用 Badge 表达兼容，不抢主品牌位置

Badge 放在包装、官网与电商的辅助位置；机身正面原则上不使用。

Works with WowNow

作为可管理的兼容认证：先通过技术测试与品牌授权，再按统一视觉规范使用；不等权并列 Logo。

设备与包装

设备正面：默认 Only POLPO；若确认 PocketEcho 长期系列化，再采用 POLPO + PocketEcho。

包装正面：POLPO → PocketEcho → 产品类型 → Badge。WowNow 不与 POLPO 等大。

准入兼容测试、版本范围与授权完成。
机身默认不使用；如需使用，单独审批。
撤销兼容失效或品牌违规时暂停并整改。
