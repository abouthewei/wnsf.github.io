# TimeTag × NODE：编排结构与展示路径

编排结构决定内容怎么组织，展示路径决定用户怎么看。

## 1. 内容编排结构

```text
                    [ 一份 TimeTag x NODE 收藏 ]
                                |
                      [ 核心主题 / 情感主张 ]
                      这份内容为什么值得留下？
                                |
               +----------------+----------------+
               |                |                |
          [ 封面 / 序 ]     [ 主体章节 ]     [ 尾声 / 延续 ]
          建立主题与期待     展开故事与内容    留下感受或参与入口
                                |
                 按适合内容的线索划分章节
                                |
        +-----------+-----------+-----------+-----------+
        |           |           |           |           |
      时间        地点        人物关系     知识主题     情绪变化
    湖人/Bling    宁夏/游记    科比/谭咏麟   Apple/山海经  迪士尼
                                |
                    +-----------+-----------+
                    |           |           |
                 [ 章节 A ]  [ 章节 B ]  [ 章节 C ]
                    |
          +---------+---------+
          |         |         |
       [节点 1]  [节点 2]  [节点 3]
          |
          +-- 主体素材：照片 / 作品 / 物件 / 影像 / 数据
          |
          +-- 标题：告诉用户如何理解这件内容
          |
          +-- 说明：背景、故事、观点或个人感受
          |
          +-- 可选扩展
                 +-- 视频 / 声音 / 实况
                 +-- 局部细节 / 档案 / 来源
                 +-- 关联节点
```

“节点”是最小展示单元：**一件素材，加上围绕它的解释与扩展内容。**

章节可以同时采用多种编排线索，例如以时间为骨架，再按地点或主题分组。

## 2. 用户展示路径

```text
                         [ 打开页面 ]
                              |
                  [ 封面 / 导语 / 品牌首页 ]
                              |
                +-------------+-------------+
                |                           |
          [ 顺序阅读 ]                 [ 空间观展 ]
          跟随编排看故事                 自由浏览选作品
                |                           |
          [ 当前节点 ]                 [ 当前主题展厅 ]
                |                           |
        +-------+-------+             [ 横向浏览作品 ]
        |               |                   |
     上一节点        下一节点          [ 点击某件作品 ]
        |               |                   |
        +-------+-------+                   |
                |                           |
                +-------------+-------------+
                              |
                      [ 聚焦单件内容 ]
                              |
              +---------------+---------------+
              |               |               |
          欣赏主视觉       阅读文字说明      播放影音
              |               |               |
              +---------------+---------------+
                              |
                      [ 进一步探索 ]
                              |
              +---------------+---------------+
              |               |               |
          展开细节档案     跳转关联内容      返回阅读/展厅
```

这是对共同体验的概括，并非每个页面、每个节点都包含全部影音或档案功能。

## 3. 两条路径如何共用同一套内容

```text
内容组织：

[序] -- [章节 A：A1 / A2 / A3] -- [章节 B：B1 / B2] -- [尾声]
                       |
          +------------+-------------+
          |                          |
          v                          v
      顺序阅读                    空间观展

 [序] -> [A1] -> [A2]          +---- 章节 A 展厅 ----+
          -> [A3]             |                    |
          -> [B1]             | [A1]  [A2]  [A3]   |
          -> [B2]             |         ^          |
          -> [尾声]           +---------|----------+
                                        |
                                  自主选择、点击细看

  强调：先后关系                 强调：并置关系
  用户：跟着故事走               用户：选择在哪里停留
```

## 4. 页面上的典型布局

```text
前九组专题的共同阅读框架
+----------------------------------------------------------+
| NODE / 专题名       [顺序阅读 | 空间观展]     全屏 / 目录   |
+----------------------------------------------------------+
|                            |                             |
|    +------------------+    |  所属主题 / 时间 / 地点      |
|    |                  |    |                             |
|    |    当前主视觉    |    |  内容标题                   |
|    |                  |    |                             |
|    |  照片 / 作品图   |    |  核心说明                   |
|    |                  |    |                             |
|    +------------------+    |  [影片] [声音] 等可选入口    |
|                            |                             |
|    图注 / 专注欣赏入口     |  延伸文字 / 资料 / 关联内容  |
|                            |                             |
+----------------------------------------------------------+
| < 上一章              当前进度 / 标题            下一章 > |
+----------------------------------------------------------+
```

前九组专题包括：科比时刻、Apple Design 的足迹、文艺复兴游记、山海经精选、英伦速写、文物修复、谭咏麟、父子宁夏亲子游记忆、上海迪士尼夜游记忆。

## 5. Bling 与湖人的扩展

Bling 与湖人在入口和节点上有所扩展，但仍接入同一条主线。

```text
Bling 首页
   |
   +--> 成就序厅 --> 数据互动节点
   |
   +--> 六个年代章节 --> 历史故事节点


湖人首页
   |
   +--> 精选旅程 / 完整典藏 --> 队史章节 --> 作品节点
   |
   +--> 我的湖人记忆 --> 个人记忆展厅
```

- **Bling**：先看成就，再读来路；将基金数据等内容转化为可互动展品。页面标注机构、人物、企业、业绩与奖项为虚构创作案例。
- **湖人**：将公共队史与私人记忆并列，让观众拥有自己的内容入口。

## 6. 共通逻辑

**主题组织章节，章节容纳节点；阅读把节点串起来，展厅把节点摆出来。**

```text
内容侧：  一个主题 --> 若干章节 --> 一组内容节点
                                      |
展示侧：                    +---------+---------+
                            |                   |
                         顺序阅读            空间观展
                            |                   |
体验侧：  被吸引 --> 看懂 --> 产生联系 --> 愿意停留 --> 再次回来
```
