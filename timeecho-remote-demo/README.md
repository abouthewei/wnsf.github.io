# TimeEcho 遥控交互验证页

左侧提供 NODE 作品、AI 音乐、音乐播放器、搜狐官网、B 站视频五个场景，右侧共用一只无屏触控遥控器。顶部切换场景，页面链接可用 `?scene=node`、`?scene=ai`、`?scene=music`、`?scene=web`、`?scene=video` 直接打开。

NODE 保留《光的重生》的原图文、顺序、场景和视频；音乐用真实音频元素验证；搜狐与 B 站用真实官网/官方播放器验证外站加载；浏览器跨域规则限制遥控器读取站内状态。五个场景没有共用虚假的内容状态。

## 真实 AI 音乐场景

新增 `?scene=ai`，来源为用户提供的[真实页面](https://nfc-web-pre.iwownow.com/fpm6HLBgDknscUyEy_IxrcdS)。保留《台灯下的温柔》的真实音频、动态背景、封面、时间戳歌词和原 React 播放器；只调整本地资源路径、路由基址，并将公开内容查询换成本地快照。它不实时同步源站后续修改，也不依赖预发布接口持续可用。

圆环复用原生旋转回调（慢转 5 秒、快转 10 秒）；播放/暂停控制真实音频，四向选择原页面播放控件，确认执行控件或切换沉浸模式，返回恢复普通视图，音量键控制歌曲音量。快捷按钮支持前后 5 秒、沉浸切换和回到开头。原 `?scene=music` 已改称“音乐播放器”，原有曲目和导入功能保留。

## 多场景操作

NODE、AI 音乐和音乐播放器可以由遥控器直接操作各自的同源演示接口。搜狐与 B 站作为真实跨域站点嵌入：网页内容可见，但演示页不能访问其内部 DOM 或播放器状态，站内浏览和视频播放请使用左侧原生控件。不要将外站场景视作完整遥控兼容验证；要实现遥控器控制，需要浏览器扩展或有权限的原生宿主适配。

音乐播放器预置 3 首原创程序合成的 32 秒演示音轨，**不是 AI 生成歌曲**。可点击“导入我的音频”导入实际 AI 音频，文件通过本地 Blob URL 使用，不上传。支持选曲、播放/暂停、上一首/下一首、列表/单曲/关闭循环、进度与音量；浏览器不支持的音频格式会报错。音频导入需在页面上选择文件，遥控器不代替系统文件选择器。

普通网页场景直接嵌入搜狐官网首页，提供另开官网链接。此环境中搜狐首页实际嵌入成功；但浏览器跨域规则禁止演示页读取站内 DOM，因此遥控器不能控制搜狐内部导航、焦点或滚动。旧小红书本地示例保留在 `web/` 源码。

视频场景嵌入 Bilibili 整站 https://www.bilibili.com/，不是仅嵌播放器。本次浏览器验证已显示完整首页；若 B 站调整嵌入策略，可使用右上角入口另开官网。浏览器跨域限制下遥控网页无法读取或控制站内内容。

每次切换场景重新载入该示例，停止旧音频，清空待执行指令。新增 scene/session 校验、过期指令拒绝和序号去重，避免旧场景的消息作用于新场景。本地导入只在当前音乐页面会话有效。

## 启动

需要 Python 3，不需要 npm 安装或构建。

```sh
cd timeecho-remote-demo
python3 serve.py
```

打开 <http://127.0.0.1:8765>。也可在 macOS 双击 `start.command`，浏览器访问同一地址。终端 Ctrl+C 停止服务。

如端口占用：`python3 serve.py --port 8766`，对应访问 8766。不能直接双击 index.html，以免 file 协议影响资源读取及消息校验。服务仅监听本机回环地址，不开放局域网。

建议桌面宽度 ≥1100 px；561–800 px 保持左右分屏，手机窄屏改为上下排列。

## 现场演示

1. 点击遥控器左侧下方灰色 NFC 键，模拟识别《光的重生》。已经阅读时保留进度，不重启作品。
2. 鼠标从圆形触控面外缘起手，沿圆周拖动；或在圆环上滚轮。顺时针/向下为下一件，逆时针/向上为上一件。
3. 中央 OK 进入作品，再按 OK 展开/收起故事；返回键退出详情，恢复原位置。
4. 在第 2 件《佛罗伦萨：城市的比例》按播放/暂停，测试原文合成讲解；第 3 件为原始视频。加减键调整页面音量。
5. 在作品焦点按“上”进入工具区；左右选择顺序阅读、空间观展或目录，OK 执行。也可用遥控器下方快捷入口直接打开。
6. 目录/场景面板中，四向按空间位置移动焦点，圆环按列表顺序选择，OK 执行；橙色轮廓标明当前焦点。
7. 场景面板按返回先回目录，再按返回关闭目录；影音详情按返回先回影音列表。
8. 橙色语音侧键打开明确标注的软件模拟指令，不采集麦克风。电源键模拟待机并停止影音，点击“唤醒演示”恢复。
9. “查看交互记录”显示执行结果；“重置演示”回作品首页并恢复音量 50%。

键盘在外层演示页获得焦点时：←/→ 对应圆环前后选择，↑/↓ 对应方向键，Enter 确认，Esc 返回，空格播放/暂停，Home 作品首页，M 目录。点击左侧 iframe 后，键盘由原 NODE 页面接收，行为遵循原页面；点击右侧按钮可回到遥控键盘路径。

在阅读正文焦点下，“下”先向下滚动，正文到底后进入控件。媒体下拉框获得遥控焦点后，左右预选媒体，OK 确认播放。

## 真实能力与模拟边界

- 真实：NODE 作品渲染、46 节点切换、12 场景、详情与故事、目录焦点、原视频播放/暂停、合成讲解、页面媒体音量。
- 模拟：NFC 识别、语音意图、电源待机、状态灯；不包含 BLE、真实 NFC、麦克风采集、电视控制或真实触觉反馈。
- 音量控制的是本页面媒体、合成讲解和背景音乐，不修改操作系统音量。合成讲解的音量改变在本地录音播放上生效。
- 浏览器若限制有声播放，需要先在左侧点击播放启用声音。音视频元素实际进度前进才算播放成功，界面不模拟虚假进度。
- 每个内容资源已保存在本地。外部出处链接仍需网络；原始在线页面与本地版本相互独立。
- 这是一份作品的验证例子；主页回本作品首页，不表示已实现跨作品内容库。图中的 NFC 卡片实体与背部读卡动作不在本轮软件验证范围。

## 合成讲解说明

原页面的 6 段中文讲解使用浏览器 SpeechSynthesis，当前验证环境未稳定启动。演示适配层按原文精确匹配，将其替换为本地 WAV 播放，避免现场依赖浏览器语音服务。

音频由本机 macOS `say` 的 Tingting 中文声音生成，语速 175，经 `afconvert` 转为 PCM WAV；这是合成讲解，不是作者或人物原声。原文、音频和生成说明位于 `narration/`，没有上传第三方服务。原始内容 JSON 和 NODE 脚本没有改写。

## 开发结构

- `index.html`、`remote/demo.css`：分屏界面与代码实现的遥控器。
- `remote/demo.js`：圆周滑动、方向/实体按钮、快捷键、反馈、模拟入口。
- `bridge/node-adapter.js`：复用原 NODE API，增加空间焦点、媒体控制、上下文和消息去重。
- `bridge/scene-host.js`：音乐与网页共用的消息校验、队列、状态和销毁处理。
- `bridge/web-adapter.js`：标准 DOM 焦点、滚动、确认和同场景跨页返回。
- `ai-music/`：真实 AI 音乐页面的原始运行时、媒体、内容快照与遥控适配层。
- `music/`：音乐界面、播放器逻辑和可复现的合成音轨生成脚本。
- `web/`：原小红书本地示例保留在源码；场景入口已指向搜狐官网。
- `external/`：搜狐与 B 站官方页面/播放器的嵌入入口，明确跨域控制边界。
- `tests/scene-host.test.cjs`：重复消息、会话隔离、过期上下文和退出场景后的队列取消测试。
- `node/`：原作品资源与运行时，仅在 index.html 注入适配脚本。
- `source-manifest.json`：下载来源、版本、文件大小和 SHA-256。
- `narration/`：原文合成讲解及来源清单。
- `serve.py`：本机 HTTP 服务，支持媒体字节范围请求。
- `verify_source.py`：验证原文件完整性和合成讲解原文一致性。

后续真实硬件可通过 `window.TimeEchoDemo.send('NEXT_ITEM')` 等统一语义入口接入；物理 BLE、配对和固件协议需另做集成，不能将此函数等同于已完成硬件连接。

协议：外层发出 `timeecho-remote-v1` 的语义指令，内层回传 `timeecho-node-v1` 的 READY、STATE、ACK、NOTICE。双方校验 origin 和消息 source；序号去重，过期指令和旧上下文拒绝执行。该同源接口只用于本地演示，不作为生产安全边界。

## 检查

```sh
python3 verify_source.py
node --check remote/demo.js
node --check bridge/node-adapter.js
node --test tests/scene-host.test.cjs
```

已在 Chrome 桌面及内置浏览器检查实际联动，包括作品遍历、详情/故事/返回、目录跳转、12 场景选择、圆环拖动/滚轮、模拟入口和真实媒体进度。手机宽度检查仅为浏览器视口验证，不代表真机触控或 Safari 验证。

验证环境说明：Chrome 扩展产生过异步消息通道错误，内置浏览器注入代码产生过 MutationObserver 错误；本地源码不使用这些扩展接口。应用自身的初始化握手错误已修复，实际遥控指令和页面状态回传通过检查。

仍需后续验证：真实触控器件的刻度反馈与防误触、真实 NFC/BLE、电视/音响矩阵、物理设备音量、语音识别和长时稳定性。
