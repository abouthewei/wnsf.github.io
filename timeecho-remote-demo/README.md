# TimeEcho 遥控交互验证页

左侧提供 NODE 作品、AI 音乐、音乐播放器、搜狐官网、B 站视频五个场景，右侧共用一只无屏触控遥控器。顶部切换场景，页面链接可用 `?scene=node`、`?scene=ai`、`?scene=music`、`?scene=web`、`?scene=video` 直接打开。

NODE 保留《光的重生》的原图文、顺序、场景和视频；音乐用真实音频元素验证；搜狐和 Bilibili 使用真实官网页面。两者均可通过 TimeEcho Chrome 扩展接收遥控：方向键选择页面控件，转盘滚动页面；焦点位于可识别的进度条时，转盘调整播放进度。

在线演示：[TimeEcho 遥控交互验证页](https://abouthewei.github.io/wnsf.github.io/timeecho-remote-demo/)。

Chrome 扩展当前为 **v1.3.2**，下载包为 `downloads/timeecho-bilibili-extension.zip`，安装和更新步骤见 `extension/README.md`。扩展请求 TimeEcho 演示页、搜狐 HTTPS 子域名、Bilibili 主站和播放器的访问权限。使用网页及视频场景前，需在 Chrome 加载或重新加载扩展，并刷新演示页。

## 真实 AI 音乐场景

新增 `?scene=ai`，来源为用户提供的[真实页面](https://nfc-web-pre.iwownow.com/fpm6HLBgDknscUyEy_IxrcdS)。保留《台灯下的温柔》的真实音频、动态背景、封面、时间戳歌词和原 React 播放器；只调整本地资源路径、路由基址，并将公开内容查询换成本地快照。它不实时同步源站后续修改，也不依赖预发布接口持续可用。

圆环复用原生旋转回调（慢转 5 秒、快转 10 秒）；播放/暂停控制真实音频，四向选择原页面播放控件，确认执行控件或切换沉浸模式，返回先清除控件焦点，再恢复普通视图，音量键控制歌曲音量。快捷按钮支持前后 5 秒、沉浸切换和回到开头。原 `?scene=music` 已改称“音乐播放器”，原有曲目和导入功能保留。

## 多场景操作

NODE、AI 音乐和音乐播放器可以由遥控器直接操作各自的同源演示接口。搜狐与 B 站作为真实跨域站点嵌入；普通网页脚本不能读取它们的 DOM，因此这两个场景通过 Chrome 扩展连接。四向键选择页面控件，转盘滚动页面；焦点位于可识别的进度条时，转盘调整播放进度。

音乐播放器预置 3 首原创程序合成的 32 秒演示音轨，**不是 AI 生成歌曲**。可点击“导入我的音频”导入实际 AI 音频，文件通过本地 Blob URL 使用，不上传。支持选曲、播放/暂停、上一首/下一首、列表/单曲/关闭循环、进度与音量；浏览器不支持的音频格式会报错。音频导入需在页面上选择文件，遥控器不代替系统文件选择器。

普通网页场景直接嵌入搜狐官网首页，提供另开官网链接。安装新版扩展后，四向键选择可见控件，转盘滚动页面；焦点位于可识别的进度条时，转盘调整进度。旧小红书本地示例保留在 `web/` 源码。

视频场景嵌入 Bilibili 整站 https://www.bilibili.com/，不是仅嵌播放器。`extension/` 中的新版 Chrome 扩展在同一标签页连接 TimeEcho 控制页、Bilibili 页面及其播放器 iframe，把方向键映射到焦点，把转盘映射到页面滚动或播放器进度。若浏览器阻止嵌入，可用右上角另开官网浏览，但该新标签页不受右侧遥控器控制。

每次切换场景重新载入该示例，停止旧音频，清空待执行指令。新增 scene/session 校验、过期指令拒绝和序号去重，避免旧场景的消息作用于新场景。本地导入只在当前音乐页面会话有效。

## 启动

需要 Python 3，不需要 npm 安装或构建。

```sh
cd timeecho-remote-demo
python3 serve.py
```

打开 <http://127.0.0.1:8765>。也可在 macOS 双击 `start.command`，浏览器访问同一地址。终端 Ctrl+C 停止服务。

如端口占用：`python3 serve.py --port 8766`，对应访问 8766。扩展的本地权限当前仅覆盖 `127.0.0.1:8765`，使用其他端口时搜狐与 Bilibili 的遥控桥接不可用。不能直接双击 index.html，以免 file 协议影响资源读取及消息校验。服务仅监听本机回环地址，不开放局域网。

建议桌面宽度 ≥1100 px；561–800 px 保持左右分屏，手机窄屏改为上下排列。

## PDF 功能与交互展示页

启动后打开 <http://127.0.0.1:8765/features/>，或点击演示页右上角“功能与交互”。页面仅依据《TimeEcho Remote System Design V3》（2026.10.26）总结遥控器与盒子的功能和用户交互路径，每项标注 PDF 页码。支持设备、功能切换及 URL 分享。“交互路径”Tab 将遥控器与盒子功能分组展示；“功能总表”Tab 按遥控器与盒子硬件分组，采用“功能 / 功能定义 / 操作 / 反馈”四列，标注 PDF 页码，样式与主界面统一。

展示原 PDF 概念图和含点阵屏的遥控器方案。原文未定义的按键动作不自行补充；概念图、尺寸与性能仍属设计提案和验证目标。页面不再展示此前的优化建议、前后对比、无屏改案或马达成本估算。已有交互 Demo 独立保留，其行为不作为 PDF 内容来源。

## 核心操作与现场演示

| 场景 | 四向键 | 圆环／鼠标滚轮 | 确认与返回 |
|---|---|---|---|
| NODE 作品 | 移动焦点 | 滚动当前页面或弹窗；媒体进度条获得焦点时调整进度 | 确认当前项目；返回退出面板或上一级 |
| AI 音乐 | 选择原页面可操作控件 | 调整歌曲进度，使用原页面旋转回调 | 无焦点时确认切换普通／沉浸模式；有焦点时执行控件。返回先清除焦点 |
| 音乐播放器 | 选择歌曲或播放控件 | 默认调整进度；歌曲列表焦点下滚动列表 | 无焦点时确认切换歌词提示；有焦点时执行控件。返回清除焦点 |
| 搜狐／Bilibili | 通过 Chrome 扩展选择网页控件 | 滚动网页；可识别的播放器进度条获得焦点时调整进度 | 确认当前控件；返回清除焦点或返回页面 |

1. 选择 `NODE 作品`，点击遥控器灰色 NFC 侧键，模拟识别《光的重生》。
2. 在遥控器圆环外缘拖动画弧，或将鼠标放在圆环上滚动。打开“目录”后，圆环滚动面板，四向键移动焦点，确认键执行选择。
3. 在音乐播放器场景按播放／暂停键控制音频。圆环每步调整 5 秒；使用四向键选择控件，返回键清除焦点。预置音轨没有歌词，歌词视图显示“暂无歌词”。
4. 在普通网页或视频场景，使用安装了 v1.3.2 扩展的 Chrome 等待页面显示“遥控已连接”，再使用方向键、确认键和圆环。
5. 橙色语音侧键打开软件模拟指令，不采集麦克风。电源键模拟待机并停止影音，点击“唤醒演示”恢复。交互结果可在“查看交互记录”中查看。

键盘四向键对应焦点移动，`Enter` 确认，`Esc` 返回，空格播放／暂停，`Home` 回作品首页，`M` 打开 NODE 目录。圆环滑动可通过鼠标拖动圆周或在圆环上滚动来模拟。

## 真实能力与模拟边界

- 真实：NODE 作品渲染、46 节点切换、12 场景、详情与故事、目录焦点、原视频播放/暂停、合成讲解、页面媒体音量。
- 模拟：NFC 识别、语音意图、电源待机、状态灯；不包含 BLE、真实 NFC、麦克风采集、电视控制或真实触觉反馈。
- 音量控制的是本页面媒体、合成讲解和背景音乐，不修改操作系统音量。合成讲解的音量改变在本地录音播放上生效。
- 浏览器若限制有声播放，需要先在左侧点击播放启用声音。音视频元素实际进度前进才算播放成功，界面不模拟虚假进度。
- 每个内容资源已保存在本地。外部出处链接仍需网络；原始在线页面与本地版本相互独立。
- 这是一份作品的验证例子；主页回本作品首页，不表示已实现跨作品内容库。图中的 NFC 卡片实体与背部读卡动作不在本轮软件验证范围。

## 合成讲解说明

原页面的 6 段中文讲解使用浏览器 SpeechSynthesis，当前验证环境未稳定启动。演示适配层按原文精确匹配，将其替换为本地 WAV 播放，避免现场依赖浏览器语音服务。

音频由本机 macOS `say` 的 Tingting 中文声音生成，语速 175，经 `afconvert` 转为 PCM WAV；这是合成讲解，不是作者或人物原声。原文、音频和生成说明位于 `narration/`，没有上传第三方服务。原始内容 JSON 和 NODE 脚本没有改写。

## 开发结构

- `index.html`、`remote/demo.css`：分屏界面与代码实现的遥控器。
- `remote/demo.js`：圆周滑动、方向/实体按钮、快捷键、反馈、模拟入口。
- `bridge/node-adapter.js`：复用原 NODE API，增加空间焦点、媒体控制、上下文和消息去重。
- `bridge/scene-host.js`：音乐与网页共用的消息校验、队列、状态和销毁处理。
- `bridge/web-adapter.js`：标准 DOM 焦点、滚动、确认和同场景跨页返回。
- `ai-music/`：真实 AI 音乐页面的原始运行时、媒体、内容快照与遥控适配层。
- `music/`：音乐界面、播放器逻辑和可复现的合成音轨生成脚本。
- `web/`：原小红书本地示例保留在源码；场景入口已指向搜狐官网。
- `external/`：搜狐与 Bilibili 整站嵌入页；跨站遥控指令经浏览器扩展传递。
- `extension/`：Chrome 扩展桥接与安装说明；适配 TimeEcho 演示页、搜狐 HTTPS 子域名、Bilibili 主站及播放器。
- `downloads/timeecho-bilibili-extension.zip`：可加载的扩展包。
- `tests/scene-host.test.cjs`：重复消息、会话隔离、过期上下文和退出场景后的队列取消测试。
- `node/`：原作品资源与运行时，仅在 index.html 注入适配脚本。
- `source-manifest.json`：下载来源、版本、文件大小和 SHA-256。
- `narration/`：原文合成讲解及来源清单。
- `serve.py`：本机 HTTP 服务，支持媒体字节范围请求。
- `verify_source.py`：验证原文件完整性和合成讲解原文一致性。

后续真实硬件可通过 `window.TimeEchoDemo.send('NEXT_ITEM')` 等统一语义入口接入；物理 BLE、配对和固件协议需另做集成，不能将此函数等同于已完成硬件连接。

协议：外层发出 `timeecho-remote-v1` 的语义指令，内层回传 `timeecho-node-v1` 的 READY、STATE、ACK、NOTICE。双方校验 origin 和消息 source；序号去重，过期指令和旧上下文拒绝执行。该同源接口只用于本地演示，不作为生产安全边界。

## 本地检查命令

```sh
python3 verify_source.py
node --check remote/demo.js
node --check bridge/node-adapter.js
node --test tests/scene-host.test.cjs
```
