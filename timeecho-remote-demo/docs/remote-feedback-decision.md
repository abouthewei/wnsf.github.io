# 遥控器无屏反馈方案

> 历史讨论记录，已退出功能展示页。当前 `features/` 仅总结原 PDF 的功能与交互，以下建议不代表 PDF 内容或当前页面方案。

更新：2026-10-31。该文档记录在 V3 基础上收敛的项目方向；不修改原 PDF，也不表示硬件已实现或验证。

## 当前方向

- 取消 32 × 16 点阵屏。实体转环、四向与确认、返回、主页、播放暂停、音量、Card、PTT 和电源操作保留。
- 保留简单状态、独立麦克风、电量指示。麦克风指示必须与实际采集状态同步。
- 内容加载、曲名、进度和音量交给大屏；无电视时通过所接音箱提供按需提示。盒子不默认内置功率扬声器。
- 震动只用于关键事件，不给普通按键或转环每个刻度叠加震动。

## 反馈分工

| 事件 | 遥控器 | 盒子 / 输出设备 |
| --- | --- | --- |
| Card 启动扫描 | 状态灯提示扫描 | 必要时说明碰读姿势 |
| 读卡成功 | 一次短震，停止扫描 | 校验授权、加载内容；就绪再提示 |
| 读卡失败 / 超时 | 两次短震与状态灯 | 大屏或音箱说明原因，Card 可重试 |
| 正在采集语音 | 独立麦克风指示持续亮起 | 大屏显示录音状态；无电视时由所接音箱提示 |
| 停止采集语音 | 麦克风指示熄灭 | 处理命令或预览录音 |
| 低电量 / 连接异常 | 简单指示，提前提醒 | 给出充电 / 重连入口 |
| 普通浏览、音量操作 | 机械手感，无额外震动 | 大屏或按需声音反馈 |

一次、两次短震是当前建议节奏；时长、强度、识别率、静音环境噪声和无障碍反馈需样机测试。读卡成功不等于作品已就绪。

## 震动选型与成本

| 候选 | 约万台规模的器件粗估 | 用途 |
| --- | --- | --- |
| LRA 线性谐振马达＋专用驱动 | ¥6–18 / 台 | 优先试样，比较短震清晰度与启停表现 |
| ERM 偏心转子马达＋简单驱动 | ¥2–6 / 台 | 成本与手感对照，重点比较启停、嗡声和辨识度 |

这些数值来自项目讨论的工程估算，不是供应商报价或采购承诺。不含固定与减振结构、装配测试、调校研发等成本，不能直接当作整机增量成本。取消点阵后可能节省成本，但尚未核算净节省金额。

定型前比较真实握持与桌面噪声，检查固定结构、瞬时启动电流、低电量下 NFC / BLE 稳定性和真实使用续航。优先试样不等于已锁定料号。
